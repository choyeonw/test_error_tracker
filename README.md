# 시험 오답 유형 분석 및 취약 개념 관리 서비스

틀린 문제를 기록하고, 자주 틀리는 과목과 개념을 확인하는 웹 서비스입니다.

## 사용하기

1. [서비스 열기](https://testerrortracker.vercel.app/)
2. 이메일, 비밀번호, 화면에 표시할 이름으로 회원가입하기
3. 로그인한 뒤 오답 등록하기
4. 오답 목록에서 검색하거나 내용을 펼쳐 확인하기
5. 과목별 오답 비중과 개념별 복습 우선순위 확인하기

## 주요 기능

- 오답 날짜, 과목, 단원, 개념, 오답 유형, 난이도 기록
- 틀린 이유와 문제집 정보 등은 선택해서 기록
- 오답 검색, 상세 보기, 수정, 삭제
- 과목별 오답 비중과 개념별 오답 횟수 분석
- 이메일·비밀번호 로그인 및 사용자별 오답 저장
- 회원가입 때 정한 이름을 메인 화면에 표시

## 사용 기술

- 화면: HTML, CSS, JavaScript
- 로그인 및 데이터 저장: Supabase
- 배포: Vercel

## 주요 화면

- `index.html`: 메인 화면
- `login.html`: 로그인 및 회원가입
- `register.html`: 오답 등록
- `mistakes.html`: 오답 목록
- `edit.html`: 오답 수정
- `analysis.html`: 취약 개념 분석
